# Function calling

A runnable TypeScript adaptation of the [official TypeSafe Function Calling cookbook](https://docs.typesafe.ai/cookbooks/function_calling). From the repository root, run `npm ci` and `npm run dev`, then open [the function-calling sample](http://127.0.0.1:4182/?cookbook=function-calling).

Choose a fixed command and **Run sample**. The result is a proposed function name and explicit kwargs, with omitted defaults displayed separately. Open **Jev DevTools → Flows**: the request contains all 54 answers, and the selected-argument collection exposes each omit/fill branch. No tool is executed. The output does not load market data, generate financial charts or place trades.

## Source fidelity

The port reads the upstream `dispatch.py`, `trader.py` and `spec.json` at the revision in [provenance.json](provenance.json). The original prompts and option descriptions are retained in `spec.json`; `signatures.json` extracts the annotated shapes, member order and defaults. Static metadata replaces Python signature reflection because TypeScript types are erased at runtime. The retained MIT notice is in [LICENSE.typesafe](LICENSE.typesafe).

- Each command makes **one request with 54 questions over ten tools**: one route Choice, closed-set value Choices, flag Nouls, optional stated Nouls, and a Noul per set member.
- Only the selected tool's answers are interpreted. Optional arguments omit when `P(stated) < 0.5`, contributing `1 − P(stated)` and preserving the function default. Their value answers are ignored. At exactly `0.5`, an argument is included. As upstream `read()` does, an absent presence answer contributes no presence decision.
- Choice decisions use the probability of the returned label, **not** the SDK Choice `confidence` field. A flag is true and a set member included at `P >= 0.5`. False flags and excluded members contribute `1 − P`. All member decisions count, including exclusions. There are no Score answers.
- Argument probability is the **product** of that argument's decisions. Call confidence is the **minimum individual decision mass** across the tool and selected arguments. The weakest argument uses the product and can differ from the decision that limits call confidence. No low-confidence gate is added.
- Unquestioned types retain defaults: `top_movers.limit` is an integer defaulting to `3` and has no question. `plot_price.moving_average` can remain omitted with a `null` default.
- `symbol` and `benchmark` use the same closed set but preserve different role prompts. Set values preserve signature member order.

## Sample scope

The synthetic cases cover every tool, omitted defaults, explicit false flags, set membership and an empty set, the exact `0.5` boundaries, argument roles, and a low-probability proposal with high API confidence. `fixtures.ts` contains authored probabilities. These are neither official cached answers nor measured quality, latency, confidence, usage, or savings results. The inspector's observed execution duration describes this local run only.

Server validation rejects unmatched commands and case IDs. The transport validates model, command and the complete question contract; live mode is blocked for this scenario even if a server key exists. No paid inference is authorized or implemented here.

This adaptation stops before the upstream `Call.run()` boundary. It does not port the market-data generator, Polars computations or Matplotlib charts. `flow.task()` performs real deterministic question preparation, selection, omission, closed-set assembly and confidence arithmetic; `flow.map()` / `flow.if()` expose selected argument decisions; `flow.output()` returns a value to the playground.

## Verification boundaries

`apps/playground/tests/function-calling.test.ts` checks the complete question contract against a digest independently generated by the pinned Python `all_questions()`, then executes sample flows through the public package API and real SDK with a custom fetch transport. Tests cover request count/order, every tool, chosen-only reads, omitted-value bypass, thresholds, defaults and distinct confidence arithmetic. Browser checks exercise the deep link, samples, request inspection and argument paths. No package API changes are needed.

Run `node cookbooks/function-calling/verify-browser.mjs` after building the package to reproduce local browser checks. It acquires the shared verification lock, starts and stops its own server, and writes screenshots, a recording and the answer-visit report under ignored `benchmarks/results/function-calling/browser/`. If the lock is occupied, wait for its owner to finish.
